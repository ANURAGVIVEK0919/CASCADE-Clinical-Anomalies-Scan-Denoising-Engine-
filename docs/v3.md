# Medical Denoise AI & Multi-Organ Diagnostics Workstation: Version 3.0 Flow (Explainable AI - XAI)

This document details the advanced, fully operational technical architecture and Explainable AI (XAI) data flow of the upgraded **Medical Denoise AI & Multi-Organ Diagnostics Workstation** (Version 3.0).

Version 3.0 elevates the system from a pure classification and restoration portal into an **Explainable AI (XAI)** workstation for radiological use. Radiologists can now inspect not just *what* the neural network detected, but *why* it focused on specific structures through **Softmax Confidence Score Pills** and **GradCAM Visual Attention Overlays**, backed by professional side-by-side print reports.

---

## 🏗️ Architectural Overview (Version 3.0)

The workstation integrates a multi-organ cascaded neural pipeline with an **XAI Feature Synthesizer**. The denoised reconstruction from the Stage-1 U-Net is inspected by the Stage-2 ResNet-50V2. The model regresses coordinates and computes softmax classification weights. The XAI module taps into the backend convolutional layers using TensorFlow gradients to output high-resolution attention maps, while the frontend renders adaptive color-coded bars, view controllers, and printed dual-report charts.

## 🗂️ Step-by-Step Data & Execution Flow

### 1. Unified Cascade Inference (`app.py` 🐍)
When a CT slice is processed by `/process`:
1. **Denoising Stage:** The input slice is reconstructed by `medical_ct_denoiser_full.keras` (or local mathematical smoothing filters in Git LFS fallback).
2. **Diagnostic Stage:** The restored slice is replicated to a 3-channel input array and passed to the multi-task model `medical_ct_diagnostic_model.keras` to output bounding box coordinates and classification logits.

---

### 2. Explainable AI (XAI) Synthesis (`gradcam_utils.py` 🛠️)
To provide detailed radiological evidence, the backend computes classification metrics and neural focus maps:
1. **Softmax Confidence Score & Top-2 Distribution:**
   - The diagnostic classifier outputs logits for all target categories (`[Chest, Brain, Abdomen]`).
   - The winning class score is extracted (e.g. `Brain — 98.4%`).
   - A Top-2 list is compiled showing secondary classifications to help clinical teams verify diagnostic variance (e.g. *Brain (98.4%), Chest (1.2%)*).
2. **GradCAM Convolution Layer Gradient Mapping:**
   - A sub-model maps the network's input to the backbone's final activation layer (`model.get_layer("resnet50v2").get_layer("post_relu").output`) and the classification output.
   - Using `tf.GradientTape`, the gradient of the target class score is computed w.r.t the feature map.
   - Feature maps are weighted by the global average pooled gradients and normalized using ReLU.
   - The map is scaled and converted to a `JET` color map (Blue representing low neural focus, Yellow representing medium focus, and Red representing high neural attention focus).
3. **Alpha-Blending:**
   - The grayscale restored CT slice is blended with the color-mapped attention focus matrix using `cv2.addWeighted` at `alpha=0.45` to overlay attention vectors without obstructing high-resolution structures.
4. **Fallback Radial Glow Heatmap:**
   - If model weights are absent, a local density scanner locates coordinates, and a radial gradient generator compiles a simulated glowing red attention overlay centered over the predicted coordinates.

---

### 3. Glassmorphic Frontend Visualization (`templates/index.html` 🎨)
1. **View Toggle Toolbar:**
   - Adds an interactive toolbar to switch views dynamically.
   - Click **Noisy vs Clean** to reveal the draggable split comparison slider.
   - Click **GradCAM XAI View** to inspect neural attention focuses and BBox coordinates simultaneously.
2. **Dynamic Confidence Progress Indicators:**
   - Progress bars transition color-codings based on model certainty:
     - 🟢 **Green** ($\ge 80\%$) — High clinical certainty.
     - 🟡 **Amber** ($60\% - 80\%$) — Moderate diagnostic variance.
     - 🔴 **Red** ($< 60\%$) — High diagnostic variance.
3. **Safety Low Confidence Warning:**
   - Automatically displays warning badges if the model's confidence drops below 60%, signaling the radiologist to review findings manually.

---

### 4. Side-by-Side Printable Clinical Reports (`templates/index.html` 🖨️)
- When a user triggers **"Print Official Clinical PDF Chart"**, `@media print` rules hide interactive buttons and toolbar controllers.
- The stylesheet overrides screen visibility rules to render **BOTH the restored scan comparison slider AND the GradCAM neural heatmap side-by-side (240px wide each) in high contrast**, preserving complete visual data for patient physical archives.
